# Shree Salon — Beauty Salon Website (Template 3)

Landing page for **Shree Salon**, "The No 1 Salon in Delhi" — hair straightening, skin care, face makeovers and bridal makeup.

**Style:** soft pink and coral palette, arch and circle photo shapes, curved pink testimonial band, elegant serif headings (Cormorant Garamond) with Poppins body text.

**Sections:** Hero · Our Services · About Us · Testimonials · Our Team · Best Pricing Plans · Latest News & Blogs · Newsletter · Footer.

Built with Next.js 16 (App Router), TypeScript and Tailwind CSS v4. Fully responsive (mobile, tablet, desktop).

```bash
npm install
npm run dev   # http://localhost:3000
```
